# (주)도스코 열처리 관제 대시보드 및 하네스 시스템

(주)도스코 특수마대강 연속열처리 전력·온도 통합 관제 및 엑셀 1:1 생산일지 전산화 시스템 저장소입니다. 현장 6개 열처리 설비 라인(1, 2, 3, 5, 6, 7호기)의 조업 데이터를 실시간 수집하고, 전사 ERP 및 생산일지와 동기화합니다.

---

## 서비스 배포 및 접속 링크

사내 네트워크 및 원격 환경에서 사용하는 주요 서비스 접속 주소는 다음과 같습니다. 사내망 분리 환경에 맞추어 사무실 고정망과 현장 유동망 모두에서 8089 포트로 접근할 수 있습니다.

- **사내 로컬 관제 서비스**: [http://localhost:8089](http://localhost:8089)
- **사무실 내부망 접속 주소**: `http://192.168.0.12:8089` (사무실 고정 IP 대역)
- **현장 설비망 접속 주소**: `http://192.168.10.200:8089` (현장 유동 IP / 듀얼 랜 허브 연동 대역)
- **외부 연계 AI 웹 서비스**: [https://ai-study-profile.9hyuni.workers.dev](https://ai-study-profile.9hyuni.workers.dev) (Cloudflare Workers 글로벌 엣지 무중단 서빙)

## 현재 개발 방법 및 실행 절차

시스템은 파이썬 경량 동기화 서버(`ThreadingHTTPServer`)와 현장 LS XGT PLC 통신 모듈, 정본 데이터베이스(MSSQL 2019 Standard 및 SQLite 호환 레이어)로 구동합니다.

PowerShell 터미널에서 다음 명령을 실행하여 서버 데몬을 구동합니다.

```powershell
# 1. 파이썬 사내 동기화 및 관제 데몬 실행 (8089 포트)
python dosko_sync_server.py

# 2. 백그라운드 구동 상태 및 포트 리스닝 확인
netstat -ano | findstr 8089
```

서버 구동 시 현장 PLC(`192.168.0.3:2004`) 데이터 수집, 18개 클라이언트 타겟 파일 SHA-256 무결성 검증, 사번 기반 RBAC 인증 체계가 자동으로 활성화됩니다.

## 망분리 환경 듀얼 네트워크 구성 방법

사무실 고정 IP망(`192.168.0.x`)과 현장 유동 IP망(`192.168.10.x`)이 물리적으로 분리된 환경에서는 서버 PC의 듀얼 랜(또는 USB 랜 허브)을 활용해 네트워크 충돌 없이 연결합니다.

- **사무실 랜 어댑터**: IP `192.168.0.12` / 서브넷 `255.255.255.0` / 기본 게이트웨이 `192.168.0.1` (외부 인터넷 출구)
- **현장 랜 어댑터 (USB 허브)**: IP `192.168.10.200` / 서브넷 `255.255.255.0` / **기본 게이트웨이 공란(비워둠)**
- **게이트웨이 분리 효과**: 현장망 게이트웨이를 비워두면 현장 태블릿 통신만 현장 랜으로 처리하고, 외부 인터넷 검색 및 클라우드 통신은 사무실망으로만 흐르므로 인터넷 끊김이 전혀 발생하지 않습니다.

## 보안 및 인증 가드레일

작업자 인증 편의성과 전산 보안을 동시에 만족하기 위해 단계별 보안 정책을 적용했습니다.

- **초기 비밀번호 규칙**: 입사 초기 비밀번호는 `사번 + 생년월일 6자리`로 자동 부여되며, 첫 로그인 시 강제 변경 안내 창이 표시됩니다.
- **현장 전용 6자리 텐키패드**: 터치스크린과 현장 장갑 착용 환경을 고려해 가상 숫자 패드로 안전하게 입력합니다.
- **비밀번호 오류 차단 정책**: 4회 오류 시 경고 모달을 띄우고, 6회 연속 실패 시 계정을 즉시 잠금(`is_locked = 1`) 처리하여 무차별 대입 공격을 차단합니다.
- **잠금 해제 절차**: 계정 잠금 발생 시 관리자(전산실) 승인 또는 인증 관리 화면에서 안전하게 초기화합니다.
