# 📖 물류센터 온보딩 문서 가이드 (Overview & Documentation Guide)

> 본 저장소(`test-01`)는 스마트 물류센터 신규 입사자 및 현장 작업자의 빠른 업무 적응과 안전한 현장 운영을 돕기 위해 제작된 **온보딩 교육 문서 모음**입니다.

---

## 🎯 문서 작성 목적
1. **무사고 현장 조성**: 물류센터 내 안전 10대 수칙 및 비상대응 절차를 명확히 안내하여 산업재해를 예방합니다.
2. **공정 표준화(SOP)**: 입고부터 출고까지 각 공정의 표준 작업 절차를 수립하여 오출고 및 재고 오차를 최소화합니다.
3. **디지털 현장 적응**: 현장에서 활용되는 WMS(창고관리시스템) 및 모바일 단말기(PDA)의 조작법을 체계화합니다.

---

 ├── 📄 02_안전보건수칙_및_비상대응.md         # 2장: 필수 개인보호구(PPE), 10대 안전수칙, 비상대응 SOP
 ├── 📄 03_센터구조_및_동선체계.md           # 3장: 구역(Zone) 구분, 로케이션 주소 체계, 통행 원칙
 ├── 📄 04_핵심운영프로세스.md              # 4장: 입고 -> 적치 -> 피킹 -> 포장 -> 출고 표준 흐름

 ├── 📄 07_근무수칙_복무규정_및_FAQ.md       # 7장: 교대근무 시간표, 복무/복장 규정, 신규자 빈출 FAQ
 └── 📄 logistics_onboarding_guide.md     # [통합본] 전 챕터를 한 번에 볼 수 있는 가이드북
